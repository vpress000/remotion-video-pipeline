# public/audio

Drop **royalty-free** background-music tracks here (`.mp3` / `.wav`).

- Reference a track from a VideoSpec via `music.trackSrc` (just the filename, e.g. `"calm-uplift.mp3"`).
- The renderer loads it with Remotion's `staticFile("audio/<filename>")`.
- Audio files are **git-ignored** so no copyrighted media is committed — keep your license records outside the repo.

Suggested royalty-free sources: your own licensed library, Epidemic Sound, Artlist, or Pixabay Music (verify each track's license).
